颜色范围定义 (HSV 颜色空间)
在计算机视觉中，HSV颜色空间比BGR颜色空间更适合进行颜色分割和检测。HSV分别代表色调（Hue）、饱和度（Saturation）和明度（Value）。下面是对HSV各个分量的详细解释：

Hue（色调）：代表颜色的类型，取值范围为 0-179 度。在OpenCV中，0 表示红色，60 表示黄色，120 表示绿色，180 表示青色。
Saturation（饱和度）：代表颜色的纯度，取值范围为 0-255。0 表示灰色，255 表示完全饱和。
Value（明度）：代表颜色的亮度，取值范围为 0-255。0 表示黑色，255 表示白色。
为了检测特定颜色，需要定义颜色在HSV空间中的上下限范围。这里是一些常用颜色的范围：

红色：

红色在HSV空间中有两个范围，一个是低端的红色，另一个是高端的红色。
低端红色范围：Hue 从 0 到 10，Saturation 和 Value 可以是 70 到 255。
高端红色范围：Hue 从 170 到 180，Saturation 和 Value 可以是 70 到 255。
绿色：

绿色范围：Hue 从 36 到 70，Saturation 和 Value 可以是 25 到 255。
蓝色：

蓝色范围：Hue 从 94 到 126，Saturation 和 Value 可以是 80 到 255。
黄绿色：

黄绿色范围：Hue 从 45 到 90，Saturation 和 Value 可以是 50 到 255。
其他颜色：

# 定义颜色范围（HSV颜色空间）
